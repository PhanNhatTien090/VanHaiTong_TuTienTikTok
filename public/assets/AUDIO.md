# Audio ledger — 31/10/2026, v6

- `meditation-loop.wav`: original 64-second stereo pentatonic composition generated by `scripts/make-ambience.py`, 24 kHz PCM16. Four related phrases; plucked harmonics, sparse singing-bowl synthesis, breathing pad and wrapped delay tails. No third-party music samples. Peak normalized to 0.8. Exact wrap math tested technically; perceptual seam/music quality still needs listening.
- `audio.js`: original Web Audio effect cues for cultivation, likes/flowers, join, sword, attack, boss, lotus, dragon, breakthrough, skin and victory. Rate limits and a compressor reduce crowd overlap. Procedural bed is a fallback only when HTML Audio is unavailable.
- `voice-welcome.mp3`: VieNeu-TTS v3 Turbo, giọng Thiền Tâm Đức + hậu kỳ tongsu (v7). Bản Edge cũ lưu ở data/voice-welcome-edge-backup.mp3.
- Dynamic event speech (v7): `speech.mjs` + `scripts/vieneu_worker.py`, VieNeu-TTS v3 Turbo local (không gửi tên ra ngoài). Fallback: `scripts/speak.py` edge-tts NamMinh (online, gửi tên công khai + câu thông báo tới Microsoft). Cache tối đa 400 clip ở data/speech.

Playback: one background file loops; event SFX use Web Audio; voice queue serializes announcements and ducks music. Six pending announcements maximum, repeated ordinary action cooldown 6.5 seconds/person/effect, expires after 25 seconds. Quests/gifts/breakthrough/join take priority under load; repeated spam is not read endlessly. Names and action captions accompany narration; camera focuses when speech actually starts.

Autoplay: overlay attempts to start; a denied autoplay request is reported, never silently shown as working. Click ♫ or Audio settings > Thử nhạc + hiệu ứng + giọng in the source interaction view. Enable Turn on sound for LIVE Studio Link. Only one audible source should be active to avoid echo from admin/preview tabs.

Validation: file generation, actual online TTS API returned an MP3, WAV MIME type, synthesis scheduling/control tests, bounded queue/cancellation, camera transforms and source access rules. Not yet critically listened through TikTok on a phone; no claim that stream audio routing or subjective mix is verified by those tests.
