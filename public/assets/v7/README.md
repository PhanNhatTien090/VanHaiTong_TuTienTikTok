## V7 production logic
- Seven original V7 variant families + six V6 signature forms = **13 special visual identities** with actual existing in-game technique IDs. They do not add new stat advantages.
- Six gift classes: 100, 500, 700, 1000, 1500, 2000+ coins. Gift contribution is server-authoritative; no fabricated HP/damage.
- Three overlay states: charge pressure, 90ms frozen-looking impact, translucent fracture and ring decay.
- 6 additional synthesized sound categories, existing audio compressor and voice cap, no autoplay bypass.
- Light / crowded / pressured / reduced-flash / reduced-motion are first-class; never halt or slow the authoritative match clock.
